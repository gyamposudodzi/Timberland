Single-file Prisma schema (`schema.prisma`) targeting a PostgreSQL datasource via `prisma-client-js`, organized into logical sections separated by comment headers: enums (Role, ShipmentStatus, PaymentMethod, NotificationChannel, NotificationLogStatus), identity/access (User with role-based access), pricing configuration (ServiceZone × ServiceLevel → RateRule with composite unique on zoneId+serviceLevelId), address book (Address linked to both User and ServiceZone), shipment lifecycle (Shipment → Parcel + TrackingEvent with dual named relations SenderAddress/RecipientAddress and self-referencing RecordedByUser), and notifications (NotificationPreference per user/channel, plus audit log NotificationLog). Relationships use explicit `@relation` tuples with cascade deletes for child-owned records (Parcel, TrackingEvent, Address→User) and set-null for optional references (Address→ServiceZone, TrackingEvent→RecordedByUser). A single migration directory (`migrations/20261018135712_init/migration.sql`) plus `migration_lock.toml` tracks DB evolution. `seed.ts` is an idempotent bootstrap that deletes all tables in reverse dependency order, then creates demo zones, service levels, a full rate matrix, two seeded users (customer + ops staff with bcrypt-hashed passwords), three recipient addresses across zones, and three sample shipments with tracking timelines generated via an external `generateTrackingNumber` helper from `../lib/tracking-number`.
