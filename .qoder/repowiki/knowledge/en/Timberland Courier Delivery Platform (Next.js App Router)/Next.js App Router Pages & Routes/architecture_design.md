Routes follow the Next.js App Router convention: `app/layout.tsx` is the root layout providing global metadata (title template, description, `metadataBase` from `NEXT_PUBLIC_APP_URL`), font variables via `next/font/google`, and wrapping `<SiteHeader>` / `<main>` / `<SiteFooter>`. Static/marketing pages live as single-file route segments (`/login`, `/signup`, `/pricing`, `/quote`, `/help`, `/legal`, `/verify`). The `/track/[trackingNumber]` segment enables guest shipment lookup without authentication. The `/account/*` subtree is gated by `AccountLayout`, which calls `auth()` from `@/lib/auth` and redirects unauthenticated users to `/login`, then renders a sidebar navigation over child pages (`dashboard`, `new-shipment`, `addresses`, `notifications`, `[id]`). The `/api/auth/[...nextauth]/route.ts` re-exports NextAuth handlers from `@/lib/auth`, making it the sole auth endpoint. Global error boundaries (`error.tsx`, `global-error.tsx`) and SEO helpers (`robots.ts`, `sitemap.ts`) sit at the app root alongside shared CSS and favicon.
