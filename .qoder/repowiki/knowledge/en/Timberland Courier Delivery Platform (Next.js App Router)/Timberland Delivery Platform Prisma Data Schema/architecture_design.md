Single-file Prisma schema (`schema.prisma`) targeting a PostgreSQL datasource via `prisma-client-js`. Domain is organized into logical sections: identity/access (`User`, `Role`), pricing configuration (`ServiceZone`, `ServiceLevel`, `RateRule` with composite unique on zone+level), address book (`Address` linked to both user and zone), shipment lifecycle (`Shipment`, `Parcel`, `TrackingEvent` with dual relation names `SenderAddress`/`RecipientAddress` and a self-referencing `RecordedByUser`), and notifications (`NotificationPreference`, `NotificationLog`). Relationships use explicit `@relation` fields with cascade or set-null delete strategies. A single migration directory (`migrations/20261018135712_init/`) plus `migration_lock.toml` tracks DB evolution. `seed.ts` bootstraps demo data (zones, levels, rate matrix, a verified customer, three sample shipments) using `bcryptjs` for password hashing and an external `generateTrackingNumber` helper from `../lib/tracking-number`.
