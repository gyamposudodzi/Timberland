The app follows the Next.js App Router layout: `app/` holds route pages (customer account, tracking, quote, pricing, help/legal, plus staff-only `/ops`), `components/` is split by feature (`account`, `auth`, `layout`, `ops`, `quote`, `shipment`, `tracking`, `ui`), and `server/` contains Server Actions + services that own business logic. Cross-cutting concerns live in `lib/` (Prisma client via `db.ts`, NextAuth config via `auth.config.ts` + `auth.ts`, Zod validation, crypto, rate limiting, pricing, shipment status, tracking number parsing, notifications). Middleware guards only `/account/*` routes; `/ops` is gated through role checks inside Server Actions. Database schema and seed live under `prisma/`. Unit tests use Vitest (`tests/*.test.ts`) while end-to-end flows are covered by Playwright under `tests/e2e/`.
