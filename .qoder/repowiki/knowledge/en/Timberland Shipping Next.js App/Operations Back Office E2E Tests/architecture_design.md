Single Playwright test file (`tests/e2e/ops.spec.ts`) that drives a real browser against the running app. It reuses shared helpers from `./helpers` (`findShipmentIdByStatus`, `closePrisma`) for DB-backed setup and teardown. The spec groups scenarios under `test.describe("back office")` and exercises three user roles implicitly through two fixture accounts (`demo@timberland.example` as customer, `ops@timberland.example` as operator). A local `login` helper and a retry-aware `submitUntil` helper encapsulate auth flow and server-action click semantics; there are no component or page-object files in this scope — the ops UI itself lives outside this module.
