The root is a single Next.js app that composes five child layers: `app_routes` (App Router pages) call into `server_actions` (Prisma-backed server actions), which in turn use `shared_lib` for auth, env, validation, pricing/zone/domain logic and email; `database_schema` (Prisma schema + migrations + seed) underpins both `shared_lib` and `server_actions`, while `ui_components` is consumed by `app_routes`. Cross-child wiring happens at three points: (1) `next.config.ts` enables Tailwind v4 via Turbopack so every layer shares one CSS pipeline; (2) `middleware.ts` uses NextAuth with an edge-safe matcher on `/account/:path*` to gate the authenticated customer area uniformly across all route children; (3) `docker-compose.yml` provisions the local PostgreSQL instance (`timberland/timberland/timberland`) that both dev and Playwright E2E tests consume. The `types/next-auth.d.ts` file extends NextAuth's session shape so the route and component layers share one user type without importing from the server-only `shared_lib`.
