Requires a running PostgreSQL instance whose connection string is provided via `DATABASE_URL` (see `.env.example`). Database bootstrap: `npm run db:migrate` (dev), `npm run db:deploy` (prod), `npm run db:seed` to populate initial zones/service levels, `npm run db:studio` for the Prisma GUI. Build sequence runs `prisma generate` before `next build`. E2E suite uses Playwright (`npm run test:e2e`); unit tests use Vitest (`npm run test`).
